# Credits

Mogger Mon is built from a retained Phaser battle-game codebase plus original Mogger Mon art, copy, UI, and launch tooling.

## Current Mogger Mon Work

- Mogger Mon creature sprites, icons, starter flow, battle labs, move labs, and launch UI direction were produced for this project.
- Runtime branding uses Mogger Mon, Mogmaster, Maxx, Cryotank, BrainDance, Zaza, relic, archive, and technique terminology.
- Replacement planning lives in the commercial-asset sweep docs and redo packs in this repository.
