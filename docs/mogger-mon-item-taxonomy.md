# Mogger Mon Item Taxonomy

This is the current public-facing naming and visual direction for the launch item pass.

## Core Categories

- `Former food consumables -> Zaza`
  - Public fantasy: packets of pills / biotech stash / weird consumable dose.
  - Visual direction: blister packs, pill cards, foil packets, capsule strips.
  - Example names: `Pulse Zaza`, `Guard Zaza`, `Chaos Zaza`.

- `Technique media -> BrainDance`
  - Public fantasy: black-market skill media, small cyberpunk discs/chips that load techniques.
  - Visual direction: compact CDs, neon optical wafers, chrome data chips, memory media.
  - Example names: `BrainDance 024 - Volt Burst`.

- `Capture devices -> Cryotanks`
  - Public fantasy: compact cryo containment tanks used to lock and transport captured Mogger Mon.
  - Visual direction: mini cryo canisters, glass fluid chambers, sealed capsule tanks.
  - Example names: `Cryotank`, `Grand Cryotank`, `Crown Cryotank`.

## Naming Rules

- Keep `BrainDance` exclusive to move-learning tech.
- Keep `Cryo` / `Cryotank` exclusive to capture devices.
- Keep `Zaza` exclusive to the food-consumable layer.
- Avoid reusing one category label across two systems.

## UI Notes

- Battle command button for capture should use a short label: `Cryo`.
- Archive / move-learning surfaces should use `BrainDance` or `BrainDances`.
- Reward / held-item / encounter copy should prefer `Zaza` over generic snack or fruit terms.

## Remaining Rename Buckets

- Maxx/form items that still sound too close to stock monster-RPG stones.
- Memory-disc style items that should visually align with the `BrainDance` media family.
- Capture-adjacent charms and helper items so they read as `Cryo` gear, not tagging gear.
- Mystery encounter copy that still references old food/item metaphors.
- Any launch-facing item icon that still looks like a palette-swapped inherited prop instead of a custom Mogger Mon object.
